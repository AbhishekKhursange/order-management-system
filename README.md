# 📦 Order Management System

A CRUD-based product management dashboard with React frontend 
and Spring Boot REST API backend.

## 🚀 Live Demo
- 🌐 [View Live App](https://order-management-frontend-sigma.vercel.app)

## 🛠️ Tech Stack
- **Frontend:** React JS, Bootstrap (folder: order-management-frontend)
- **Backend:** Java, Spring Boot, REST API (folder: order-management-backend)
- **Deployment:** Vercel (Frontend), Render (Backend)
